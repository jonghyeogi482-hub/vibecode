# 🎵 Vibecode - Cursor를 이용한 바이브 코딩 강의

## 📚 강의 소개

**Vibecode**는 AI 코딩 어시스턴트 **Cursor**를 활용한 현대적인 프로그래밍 강의입니다. 
이 강의는 개발자들이 Cursor의 강력한 기능들을 활용하여 더 효율적이고 창의적인 코딩을 할 수 있도록 안내합니다.

## 🎯 강의 목표

- ✨ Cursor의 기본 기능 및 고급 활용법 이해
- 🚀 AI 기반 코드 자동완성 및 생성 활용
- 💡 효율적인 개발 워크플로우 구축
- 🔧 실전 프로젝트를 통한 실습

### 1. Cursor 기초
- Cursor 설치 및 환경 설정
- 기본 인터페이스 이해
- 단축키 및 설정 커스터마이징

### 2. AI 기능 활용
- 코드 생성 및 자동완성
- Chat 기능 활용법
- 코드 분석 및 리팩토링

### 3. 고급 기능
- 프롬프트 최적화
- 컨텍스트 관리
- Multi-file 작업

### 4. 실전 프로젝트
- 웹 애플리케이션 개발
