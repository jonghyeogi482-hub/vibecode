# 🎵 Vibecode - Cursor를 이용한 바이브 코딩 강의

## 📚 강의 소개

**Vibecode**는 AI 코딩 어시스턴트 **Cursor**를 활용한 현대적인 프로그래밍 강의입니다. 
이 강의는 개발자들이 Cursor의 강력한 기능들을 활용하여 더 효율적이고 창의적인 코딩을 할 수 있도록 안내합니다.

## 🎯 강의 목표

- ✨ Cursor의 기본 기능 및 고급 활용법 이해
- 🚀 AI 기반 코드 자동완성 및 생성 활용
- 💡 효율적인 개발 워크플로우 구축
- 🔧 실전 프로젝트를 통한 실습
